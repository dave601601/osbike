### ablation 3종 — 셋 다 음성 (pi/v 초기화 bit-identical 대조, 같은 seed 끼리 비교)
| | 총합 | vs 대조 | 판정 |
|---|---|---|---|
| 프레임 스태킹 8 (4→8) | 420 (s0) | -3, p=0.82 | **효과 없음** |
| SPR (K=8 잠재예측) | 450±12 (4 seed) | **+13 ±15, t=1.74** | **유의하지 않음** |
| COMA (counterfactual) | 286 (s0) | **-137** | **명확히 해로움** |

**프레임 8 = 무효.** POMDP 처방은 임계지 gradient 가 아니다 — 4프레임이 이미 충분하고
8은 obs 69→121 로 샘플효율만 손해(학습 리턴도 낮음). 이건 README 에 이론 주장으로 남김.

**SPR = 유의하지 않음 (★ n=1 이었으면 오판할 뻔한 사례).**
| seed | 대조 | SPR | 차이 | paired p |
|---|---|---|---|---|
| 0 | 423 | 450 | **+27** | 0.002 |
| 1 | 413 | 437 | **+24** | 0.010 |
| 2 | 460 | 465 | +5 | 0.64 |
| 3 | 453 | 449 | **-4** | 0.72 |

- seed 0 단독으론 +27·p=0.002 로 **명백한 개선처럼 보였다.** 4 seed 로 늘리니 평균
  **+13 ±15, paired t=1.74 (df=3, p≈0.18)** — 사전 기준(+23=1σ) 미달.
- 눈여겨볼 패턴: **대조 sd 22.8 → SPR sd 11.5 로 절반.** SPR 은 평균을 올렸다기보다
  나쁜 seed(423, 413)를 끌어올려 **분산을 줄였다**. 단 n=4 로 분산 감소를 주장하는 건
  평균 비교보다 더 약한 근거라 **가설로만** 남긴다.
- 교훈: 학습 seed 분산(1σ≈23)을 **먼저 측정해둔 것이** 잘못된 주장을 막았다.
  ablation 을 단일 seed 로 판정하면 안 된다.

**COMA = 실패, 원인 특정됨.** 단일 에이전트·연속행동이라 원 COMA 의 정확한 marginalize
를 기준점 하나(잔차 0 = base)로 대체 → `A=Q(s,a)-Q(s,0)`. 그런데 **Q(s,0)이
off-distribution** (정책이 0 근처를 잘 안 뽑음) → 크리틱이 학습된 적 없는 지점에서
counterfactual 을 평가. 엔트로피 -1.66 붕괴(타 런 -0.63~-0.83)가 과도하게 sharp 한
advantage 의 징후. **구현 전 docstring 에 적어둔 위험이 그대로 실현됨** — 각색이 서툴렀던
게 아니라 이 각색이 원리적으로 이 문제에 안 맞는다는 쪽에 가깝다.

## 2026-07-08 — pure RL 어블레이션: 동일 예산으로 경사 course-hold 발견 실패 (residual 확정)

### 실험 (base 없이 정책 단독, 커리큘럼 task150→dr400, 각 210M steps)
| 런 | 구성 | in-domain | 엔벨로프 |
|---|---|---|---|
| pure_dr | task ckpt 이어서 (σ가 floor 에 붙은 채) | ep_len 559 | **전 셀 0%** |
| pure_dr2 | + log_std −1.0 리셋 (`--reset-log-std`) | ep_len 622 | **전 셀 0%** |

### 진단 사슬
1. 평지(직진·선회·지연)는 CPU/MJX 모두 완벽 — 파이프라인 문제 아님.
2. 낙하 시그니처 = heading 항복(yaw −60°+, 보강② 이전 base 와 동일 모드).
3. **결정판: MJX(자기 학습 세계) 옆경사 2° 직진 0/64 (결정론)** — 프록시 전이 문제도
   아니고, **경사 course-hold 스킬 자체를 학습 못 함**. in-domain ep_len 622 는
   저경사 추첨(장수)과 경사 추첨(단명)의 혼합 평균이었음.
4. 부수 교훈: 커리큘럼이 σ를 floor 로 옮겨붙이면 새 도메인 탐색 불가 → init 시
   log_std 리셋 필요 (dr2 에서 in-domain +15% 확인). 그래도 경사는 못 넘음.

### 결론 (pure vs residual — 논문 어블레이션 축)
- 경사 코스 유지는 우리도 고전 쪽에서 **명시적 엔지니어링**(lean 스케줄+heading PI+
  k_lat+슬루 가드, 보강②)이 필요했던 구조화된 스킬 — pure RL 은 동일 예산에서
  "짧게 살고 드리프트" 국소최적에 머묾 (생존 보상이 코스 벌점을 지배).
- **base prior 는 정확히 그 스킬을 공급하고, RL 잔차는 그 위에 강건성을 공급** —
  합성(residual)이 각자 단독보다 우월. 최종 컨트롤러 = res_v2@0.5 유지.
- pure 를 살리려면(미래 과제): 경사 커리큘럼, |ct| 조기종료(항복 최적 제거),
  코스 보상 강화, 더 긴 학습. 데이터: envelope_rl_pure{,2}.json

### ★ POMDP 진단 (프레임 스태킹의 이유)
미지 지연·DR 파라미터는 잠재변수 — 단일 상태 프레임+행동 이력으로는 식별 불가
(식별에는 "명령에 대한 상태 반응" 이력 필요). res_hard2 의 저지연 붕괴가 실증.
고정 지연이면 행동이력 증강으로 정확히 MDP(delayed MDP), 미지·랜덤이면 이력 필요.
**코어 13 × 4프레임 스태킹**으로 해결 — 같은 도메인에서 ep_len 400→732.

### ★ 과작동 국소최적 (res_scale 1.0 무앵커의 함정)
스태킹+scale 1.0 은 in-domain 을 크게 올렸지만, 정책이 **공격적 진동 모드**(평지
lean RMS 3-5° vs base 0.1°)에 정착 — 혼합 평균으론 이득이라 유지되면서 쉬운 셀
희생 (MJX 결정론 평지에서도 11/64). **잔차를 평가에서 절반으로 줄이자 즉시 회복**
(평지 lean 0.52°, 전 지연 완주) = 방향은 옳고 크기가 과함. 처방: res_pen 벌점 +
scale 0.5 학습 (res_v3).

### num_envs 탐색 (RTX 4060 Ti 8GB, 사용자 주도 지수→이분 탐색)

### ★ 보상 설계 교훈: lean 벌점 캡 없으면 학습 정체 (실측)
−50·lean² 무캡 → 낙하 직전 스텝당 −30: (a) 리턴이 행동과 무관한 추락 구간에 지배 →
어드밴티지 노이즈화 → **19M 스텝 동안 KL~0.001 정체, ep_len = passive 수준**,
(b) 생존(+1) 압도 → "빨리 죽는 게 이득" 자살 균형 위험. **−50·min(lean², 0.02)
(±8° 밖 포화, 캡 −1)** 로 바꾸자 즉시 학습 (KL 0.007, 13M 스텝에 passive 2.5×).
